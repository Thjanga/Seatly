# Seatly

Spring Boot 기반 실시간 예약 및 대기 시스템

## 프로젝트 목표

예약 시스템을 직접 구현하면서 백엔드 개발에 필요한 핵심 개념을 학습한다.

- Spring Boot
- REST API
- JPA
- PostgreSQL
- Spring Security
- JWT
- Redis
- 동시성 제어
- 테스트
- Docker
- AWS
